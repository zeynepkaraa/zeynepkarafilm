# Project: Photography Portfolio

A portfolio website for a photography business. The photos are the product: the UI should stay quiet and let images lead.

## Design workflow
- Use the `ui-ux-pro-max` skill for any UI/UX decision (style, palette, typography, layout, accessibility).
- `design-md/<site>/DESIGN.md` files are reference design systems. When a visual direction is chosen, copy the chosen one (or a blend) to `DESIGN.md` at the repo root and treat it as the source of truth for tokens and components.
- Use the references for design language only. Never copy another company's name, logo or branding into the site.

## Site priorities
- Fast image loading: responsive `srcset`, AVIF/WebP, lazy loading, reserved aspect ratios (no layout shift).
- Gallery with a keyboard-accessible lightbox; meaningful alt text for every photo.
- Clear path to booking/contact on every page.
