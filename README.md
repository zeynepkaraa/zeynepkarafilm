# Photography Portfolio

Portfolio website for a photography business.

## What's in here

| Path | Purpose |
|------|---------|
| `.claude/skills/` | [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) skills (MIT). Claude Code loads them automatically in this repo. |
| `design-md/` | [Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md) collection (MIT): reference design systems (DESIGN.md files) to borrow design language from. |

## Getting started

Open the repo in Claude Code and ask for UI work, e.g.
"Build the portfolio home page with a full-bleed hero and a masonry gallery."
